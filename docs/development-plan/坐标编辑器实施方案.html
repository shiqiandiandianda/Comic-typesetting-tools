项目目标与技术选择

项目暂名 GridLens 坐标编辑器。建立两个入口共用一份数据的工作流：JSON → 编辑格框 → 导出图片，以及已有图片 → 自动检测格框 → 人工校正 → 导出 JSON。目标用户为条漫排版、图像标注和坐标设计人员。

建议采用 React + TypeScript + Vite + Fabric.js，JSON Schema 负责格式验证，OpenCV.js 在浏览器端生成格框候选。这是方案中的选型建议，依赖精确版本将在建立项目时查询稳定发布并锁定。

参考项目已核实的能力本项目取舍
Konva矩形绘制、拖动、位图导出。参考交互模型。因新增 SVG 导出要求，不作为主引擎；官方选型指南明确说明无 SVG 导出。
JSON Canvas Viewer读取带坐标的 .canvas 文件，平移与缩放。借鉴可读 JSON 与查看方式；自有格式增加测量、候选审核、资源和标注。
AntV X6fromJSON 渲染节点和连线，支持图片导出。借鉴对象列表与属性编辑。本项目核心是图像空间坐标，首版不引入流程图端口模型。
Fabric.js交互对象、选择、层次顺序，以及 JSON、SVG、图片导出。主引擎；业务 JSON 与 Fabric 内部对象隔离，避免格式被渲染库绑定。
已实际读取参考 HTML：原点左上，X 向右，Y 向下；支持 256px 网格、原图坐标指针、点击冻结、几何叠层、对象坐标表和 JSON 下载。新方案保留这些能力，并加入编辑和自动识别。

画布设置与测量功能

“底图大小”定义为画布的真实像素宽高；参考图片作为独立、默认锁定的图层，可设置透明度与适应方式。默认等比适应，避免测量时把图片拉伸。

更改画布尺寸时提供“保留对象坐标”与“按新画布缩放对象”两个选择；默认保留坐标。第二种方式明确显示 X、Y 两个缩放因子，参考图片优先等比处理。显示缩放和画布尺寸是不同设置。

  • 网格与标尺：保留 256px 默认步长，提供 16、32、64、128、256 及自定义值；吸附可独立启用。
  • 坐标指针：十字线显示画布原始 X、Y；测量模式下点击冻结，再点击解除，不与拖动选择冲突。
  • 拖框量测：临时选区显示 X、Y、W、H、右/下边界、面积和宽高比；可一键转为正式格框。
  • 两点量测：显示 ΔX、ΔY、直线距离；支持水平、垂直及任意方向；可保存为尺寸标注。
  • 格间量测：选中两个格框显示水平/垂直间距、交叠尺寸和相对画布占比。
画布坐标统一由逆视口变换得到，不能直接把屏幕 clientX/clientY 当成 JSON 坐标。参考图片检测结果另经图片到画布的变换映射；原图像素与画布像素不相同时，两套读数明确标记。

项目 JSON 规范

以 JSON Schema Draft 2020-12 提供机器可验证的格式，业务规范固定为 gridlens / 1.0.0。Schema 草案与完整示例均附在本方案目录中。

coordinateSpace固定 canvas-px。左上原点，X 向右，Y 向下；所有点均为全局画布坐标。

几何约定：矩形范围为 [x,x+width) × [y,y+height)。bbox 表示矩形几何边界，不包含描边；描边居中绘制。允许小数坐标，编辑内部保留精度，JSON 保存最多六位小数。负坐标可表示出画布，导出按 clipToCanvas 决定裁切。

导入流程：解析 → Schema 校验 → 语义校验 → 预览差异 → 应用。语义校验包括 ID 唯一、关联存在、多边形非退化/不自交、引用资源可用、资产路径不含 .. 或绝对路径。失败时保留当前画布，展示字段路径和原因，不把错误 JSON 部分应用。

画布变化即时更新“当前项目 JSON”。用户粘贴或修改“输入草稿”后点击应用，避免半段 JSON 或旧草稿覆盖最新拖动结果；有草稿时显示未应用提示，并可重置为当前项目。

参考数据兼容：提供单独导入适配器，将原查看器中的 w/h 转为 width/height，将 read_order 转为 readOrder；允许选取 report.pages 中一页或 layout。斜格/折线保持原几何类型。原气泡主体可导为带说明的包围框或文字；不声称获得了原始气泡轮廓或隐藏图层。

JSON Canvas 互通：可增加 .canvas 导入/导出适配器，转换矩形和文字；测量、识别来源、多边形等自有字段需扩展元数据保存，导出时列出不能无损映射的字段。

PNG JPG SVG 导出

导出从当前已校验的文档快照创建离屏场景，画布缩放、滚动、选择框、控制手柄和编辑器 UI 不进入图片。网格、测量线、标签、参考底图可分别勾选；默认导出格框和普通标注，关闭辅助网格及尺寸层。

格式输出规则
PNG按原始画布像素或 2×、4×倍率导出，支持透明。
JPG导出为 image/jpeg，提供质量设置；透明区域先铺用户指定的底色，默认白色。
SVG保存真实 rect、polygon、text、path 等矢量对象，设置原始 width、height 与 viewBox；参考图片以 data URI 嵌入，图片本身仍是位图。
项目 JSON恢复格框、标注、层次及资源；与图像导出分开，保留可编辑结构。

统一准备参考图片及字体，再导出；对中文、字号、描边、透明度和叠放结果做跨格式对照。外部 SVG 查看器的字体可能不同，提供保留文本的常规导出，并在交付前明确目标机器的字体约定。

长图先检测浏览器 Canvas 尺寸与内存能力，按 width×height×倍率²×4 估算单张 RGBA 缓冲占用，并考虑场景复制的额外内存；超限时提供降低倍率或分段导出。PNG/JPG 默认下载整张画布，分段导出必须显式选择。

SVG 是首版验收项：不能把 PNG 包在 SVG 标签中作为矢量导出。Fabric 官方具有 SVG 输出能力；项目只使用可被三种格式一致表达的格框与标注样式。

图片自动识别与校正

本地图片→边缘与轮廓→候选格框→人工校正→项目 JSON

首版采用浏览器端 OpenCV.js / WASM，在 Worker 中执行。图片保留原始尺寸与 EXIF 方向；识别在经过方向校正的工作副本上运行。彩色、灰度及低对比场景提供少量可理解的“边框强度、最小格子、灵敏度”设置。

  1. 灰度化和去噪；使用自适应阈值或 Canny 获得边缘。
  2. 形态学连接短裂缝；findContours 获取轮廓及层次。
  3. approxPolyDP 近似多边形；依据面积、长宽、闭合度、边线连续性判断格框候选。
  4. 处理双描边、相邻碎边和重复候选；保留真实嵌套格，不仅按重叠就删除。
  5. 把检测工作图坐标映射回原图，再映射到画布；保存候选评分和待复核状态。
  6. 用户接受、移动、缩放、补画、删除或转换为多边形；确认后导出同一套项目 JSON。

OpenCV.js 官方轮廓教程提供基础检测能力；组合筛选和格框评分是本项目拟开发的业务算法，并无现成证据保证所有条漫自动识别正确。

识别范围：优先处理清晰的矩形格框和可见的斜边。对无框镜头、复杂人物轮廓、被气泡遮挡的边界及渐隐格，用候选提示和手动补画完成。首版不自动推断台词、气泡结构及阅读顺序；需要这些能力时另加识别模块。

长图：按内存预算分块，保留交叠带并合并跨块轮廓，处理跨块的大格。识别过程可取消，重新载入图片时旧任务失效；所有 Mat、Worker 和临时图片缓冲及时释放。

“未检测到格框”与“算法运行失败”分别展示；两种情况都能进入手动绘制。候选评分用于排序，不作为正确率百分比。扁平图片只能提取可见几何，不能恢复被遮住的内容或原始图层。

代码结构与 Context7 使用

Context7 是当前文档查询工具，不是一套编码规范。本次已实际调用并核对 React、Fabric.js、Konva 文档；开发时按目标依赖版本再次核对 API，而不是直接复用旧教程。

模块职责与边界
core/document、geometry、commands纯 TypeScript 文档类型、几何计算、文档修改命令和撤销；不依赖画布引擎。
adapters/fabric业务对象与 Fabric 对象互转，视口映射，拖动/缩放状态归一化。
features/json、canvas、measure、annotate输入草稿、属性面板、格框编辑、坐标测量与标注。
features/recognition + workers可取消的本地识别任务、候选列表、人工确认及资源回收。
services/export、import、persistence统一文档快照导出、旧格式适配、IndexedDB 自动保存与项目恢复。
styles/tokens语义色、间距、字号、焦点和状态样式；界面颜色与画布颜色分别管理。
  • TypeScript strict，边界输入先验证；不使用 any 掩盖 JSON 或事件类型问题。
  • 坐标适配显式使用左上语义。Fabric 7 迁移文档记录了默认原点改为中心及事件 API 改动；开发须核对所选稳定版本，不依赖隐式默认值。
  • 缩放结束将 scaleX/scaleY 归一到业务 width/height；多选/分组操作转换为全局几何，不能把组内坐标写入 JSON。
  • React 在 Effect 中创建并清理画布实例及事件，处理 Strict Mode 的重复挂载；React 与画布仅通过适配器共享文档状态，避免循环更新。
  • JSON Schema 作为统一结构契约，用支持 2020-12 的验证器；ID、资源、路径和几何关系单独校验。未来字段走 schemaVersion 迁移。
  • 核心编辑在本地进行；OpenCV/WASM 和字体打包或本地缓存，不在测量过程中依赖远程 CDN；自动保存失败可手动下载 JSON。
  • 建立项目时查询稳定依赖、匹配 Node 运行时、提交 lockfile，并记录 Context7 库 ID、查询日期、目标版本和实际使用的 API。

自动识别基础合成矩形、双描边、叠格和跨块矩形提供确定真值；目标为清晰样本完整检出且边界误差≤2 原图像素。
真实图片优先使用参考目录中 B06（叠格）、B05（倾斜/遮挡）、B10（斜切）及其已测标注。记录精确率、召回率、几何误差及人工校正时间，不预先声称达标。
识别候选审核允许未确认候选随 JSON 保存，但保留 pending 状态并显示未确认数量；漏格始终可以手工补画。
取消与失败识别可取消；换图后旧任务不能覆盖新文档；未检出与运行失败有不同反馈。
UI 与操作替代鼠标、键盘和数值面板可完成编辑；焦点可见；375/768/1024/1440 宽度下重要内容可访问。移动端折叠属性侧栏。
交付源码、lockfile、启动说明、示例及测试记录齐全；在目标 Windows Chrome/Edge 做真实下载验证。
